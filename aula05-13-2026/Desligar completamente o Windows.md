Existem duas maneiras para desligar completamente o Windows, desativando a inicialização rápida:

1. Segure SHIFT ao clicar na opção "Desligar" do Windows
2. Abra o CMD como Administrador e digite: shutdown /s /p /t 0  
   
Ao fazer isso, vamos testar se o sistema de arquivos NTFS onde o Windows está instalado tornou-se editável.
