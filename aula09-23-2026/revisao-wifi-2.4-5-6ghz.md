# Wi-Fi: 2.4GHz, 5GHz e 6GHz

## Informações Relevantes sobre Configuração de Wi-Fi

### Frequências Disponíveis

As frequências disponíveis para Wi-Fi são: **2,4GHz**, **5GHz** e **6GHz**.

> **Nota importante sobre o Brasil:** A partir de 2027, a faixa de 6GHz será dividida no Brasil. Apenas a parte 'inferior' estará disponível para Wi-Fi, enquanto a parte 'superior' será utilizada para 5G e futuro 6G.

### SSID (Service Set Identifier)

- É o **nome da rede sem fio**
- Pode ou não ser divulgado pelo Access Point (AP)
- Quando não divulgado, os clientes devem configurar manualmente a conexão com o AP

### Segurança

Formatos de criptografia disponíveis:
- **WPA** - Wireless Protected Access (mais antigo)
- **WPA2** - Wireless Protected Access 2 (padrão atual)
- **WPA3** - Wireless Protected Access 3 (mais recente e seguro)

Utilizados na troca de informações entre o Access Point e os clientes.

### Senha

- Utilizada para autenticar ou negar acesso à Wi-Fi
- Deve ser combinada com um dos protocolos de segurança (WPA/WPA2/WPA3)

### Canal

Serve para divulgar o sinal sem interferência de outras redes sem fio.

#### Canais Disponíveis por Frequência

**2,4GHz:**
- Total de **13 canais disponíveis**
- **Canais não sobrepostos:** 1, 6 e 11 (quando largura de canal é 20MHz)
- Estes 3 canais devem ser utilizados para evitar interferência

**5GHz:**
- Múltiplos canais disponíveis
- Maior espaçamento entre canais reduz interferência

**6GHz:**
- Novos canais disponíveis com melhor separação

### Largura de Canal

Determina a taxa de transferência (velocidade). Quanto maior a largura, mais rápido o sinal. Quanto menor, menor o desempenho, mas maior alcance.

#### Larguras Disponíveis por Frequência

| Frequência | Larguras Disponíveis | Características |
|-----------|---------------------|-----------------|
| **2,4GHz** | 20MHz, 40MHz | 20MHz = melhor compatibilidade; 40MHz = melhor velocidade |
| **5GHz** | 20MHz, 40MHz, 80MHz, 160MHz | Maior flexibilidade; 160MHz = máxima velocidade |
| **6GHz** | 20MHz, 40MHz, 80MHz, 160MHz, **320MHz** | 320MHz = velocidade máxima (Wi-Fi 6E/7) |
