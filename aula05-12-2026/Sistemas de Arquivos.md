#### Para usar um dispositivo de armazenamento (e um sistema de arquivos), antes eh necessário:

1. Escolher um tipo de esquema de partições (tabela de partições) - MBR ou GPT
2. Particionar (definir onde inicia e termina uma partição, e, com isso, seu tamanho)
3. Formatar (definir um sistema de arquivos para a partição)



##### Os sistemas de arquivo mais utilizados são:

- NTFS: utilizado pela Microsoft no Windows

- exFAT: utilizado para pendrive, HD/SSD externo, cartões de memoria

- EXT4: utilizado em sistemas Linux (não obrigatório, mas comum)

- APFS: utilizado em sistemas da Apple

- FAT32: utilizado em sistemas legados



Ao formatar uma partição com um sistema de arquivos, geralmente eh possível escolher o tamanho da unidade de alocação, que eh onde os arquivos serão armazenados naquela partição.
